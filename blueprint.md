# Lotto Number Generator

## Overview

A web application that generates random lottery numbers. It provides a user-friendly interface to generate numbers, view the results, and see a history of generated sets.

## Project Outline

### Style and Design

*   **Layout:** A clean, centered layout that is mobile-responsive.
*   **Color Palette:** A modern and vibrant color scheme with good contrast.
*   **Typography:** Clear and readable fonts.
*   **Visual Effects:**
    *   Subtle background texture.
    *   Soft shadows on elements to create depth.
    *   "Glow" effect on interactive elements.
    *   Animations for the number generation.

### Features

*   **Number Generation:** Generates 6 unique random numbers between 1 and 45.
*   **Number Display:** Displays the generated numbers in a visually appealing way (e.g., as colored balls).
*   **History:** Keeps a record of previously generated number sets.
